# Проверки первой версии

## Выполнено

- `docker compose config --quiet`: успешно.
- Собраны Docker-образы backend и frontend. Все пять Go Creator-бинарников с патчем телеметрии компилируются из закреплённого upstream-коммита.
- PostgreSQL запущен и healthy. Backend и Nginx запущены. Публикуется только `127.0.0.1:8080`.
- `PYTHONPATH=backend .venv/bin/pytest backend/tests -q`: **6 passed**. Есть предупреждение зависимости Starlette о будущем переходе TestClient с httpx на httpx2.
- Тесты проверяют авторизацию, CSRF Origin, зашифрованное хранение, отсутствие секретов в ответах и журнале, формат cookies, ограничение портала, запуск/остановку subprocess, метрики, сохранение обновлённых cookies, ожидаемую auth-cookie при сохранении браузера, Bitrix cookie hosts и блокирование приватных адресов браузера.
- `frontend: npm run build`: TypeScript и Vite production build успешны.
- Playwright против живого Docker Compose: вход в админку, SSE, создание аккаунта через UI, удержание фокуса в диалоге, фильтр ошибок. Нет pageerror.
- Проверены снимки desktop 1440 px и mobile 375 px. На 375 px горизонтального переполнения страницы нет; таблица сессий имеет собственную прокрутку.
- Серверный Chromium от пользователя backend открывает настоящий сайт Телемоста; API возвращает JPEG страницы после загрузки и принимает команду Tab. Учётные данные не вводились.
- Настоящий DION Creator запущен через API с тестовым файлом без учётных данных. Процесс локально завершился с ошибкой; состояние `error` и отредактированный журнал доступны через PostgreSQL/API. Тестовые аккаунты, сессии и их журналы удалены.
- Graphify выполнен на новой кодовой базе панели: 15 файлов кода, 241 узел, 459 связей на момент анализа. Вывод сохранён вне проекта в `/tmp/codex-session-tools-fQaZDYg3/control-graph/graph.json`.
- Ponytail использован как инструкции текущей беседы. UI UX Pro Max: выполнен поиск design system и изучены правила UX/доступности. Глобальные конфигурации и hooks не менялись.

## Пока не проверено

- Завершённый вход с реальными учётными данными в VK, Телемост, WB Stream, DION и Bitrix.
- Создание реального звонка и трафик с реальным Joiner, скорость, обрывы и восстановление платформенных подключений.
- CAPTCHA с перетаскиванием, passkey/аппаратные ключи, доступность интерактивного изображения для screen reader. Это ограничения текущего удалённого браузера, описанные в README.
- Полный аудит безопасности upstream и панели, нагрузочное тестирование и рабочие сценарии нескольких администраторов.

Результаты subprocess-тестов не выдаются за доказательство работающего обхода блокировок. Точные значения RX/TX на реальном туннеле требуют проверки с вашим аккаунтом и отдельным устройством.
