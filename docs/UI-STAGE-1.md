# Этап 1 — рабочие взаимодействия

## Изменено

- `frontend/src/App.vue`: Vue Transition для разделов (ключ только `tab`), диалогов, ошибок и успешных уведомлений. API, обработчики действий и SSE-подписка не изменены.
- Добавлены только presentation hooks: временное удержание высоты раздела при переходе; блокирование ввода и скрытие от accessibility tree исчезающих элементов; восстановление доступности при повторном появлении.
- `frontend/src/style.css`: объединены два `:root` с сохранением итоговых значений. В исходном каскаде обнаружены 83 повторяющихся селектора; все 324 правила вне `:root` сохранены без изменения и в прежнем порядке. Добавлен отдельный слой взаимодействий и общие тайминги.
- Тайминги: hover/focus 150 мс; вход разделов и уведомлений 200 мс; диалоги 220 мс; выход 140 мс. Движение ограничено 5–10 px. Постоянных циклов, частиц, glitch и анимации показателей нет.
- Hover использует умеренную подсветку границы; эффекты наведения для мыши ограничены `(hover: hover) and (pointer: fine)`. Клавиатурный фокус отчётливо обозначен. При reduced motion переходы отключены, конечное состояние показывается сразу.
- Новых библиотек нет. Серверная часть, API, зависимости и конфигурация контейнеров не изменены. Пересобран и перезапущен только web.

## Проверено

- Production-сборка Vue/TypeScript/Vite внутри Docker успешна.
- Browser QA на изолированных тестовых данных, с перехватом API-запросов: переключение разделов, отображение сессий, действия start/stop, копирование ссылки и уведомление, фильтр ошибок, открытие/закрытие диалогов, Tab-цикл и возврат фокуса после Escape.
- SSE-снимки повторялись каждые 700 мс: наблюдатель DOM не обнаружил повторного запуска входной анимации раздела.
- Ширины 375, 768 и 1440 px: горизонтального переполнения страницы нет; геометрия sidebar/topbar/heading/stats/table/help/footer совпала с исходной (допуск 0,1 px).
- Reduced motion на 375 px: transition-duration диалога 0s, transform none; диалог закрывается корректно.
- Сравнение PNG в установившемся состоянии: сессии 375/768/1440 и журнал — 0% пикселей с разницей RGB > 8. Аккаунты — 0,058%, диалог — 0,255% (изменённые hover/focus-стили). Скриншоты просмотрены визуально.
- Нет ошибок JavaScript или console.error в browser QA.
- Отдельный smoke test против настоящего backend: вход администратора, получение SSE и desktop/mobile отображение успешны; тестовые данные в БД не создавались.
- В скрипте сохранены прежние API-вызовы, SSE и business handlers: сравнение с исходной версией подтвердило отсутствие изменений, кроме четырёх presentation hooks.

## Найденные особенности и ограничения

- В первом автоматизированном прогоне Chromium запретил clipboard; проверка повторена с явным разрешением clipboard и прошла. Изменений кода копирования не потребовалось.
- Каскад содержит исторические переопределения. На этом этапе они намеренно сохранены: массовая перекомпоновка стилей дала бы излишний риск для адаптивности.
- FPS и нагрузка на слабых физических устройствах не измерялись. Новые эффекты событийные, без собственных таймеров и фоновых циклов; таблицы и журнал при обновлениях не анимируются.
- Реальные звонки, авторизация сторонних платформ и передача данных повторно не проверялись: изменения относятся только к представлению.
